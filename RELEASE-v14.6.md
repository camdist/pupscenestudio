# PupScene Studio v14.6 — Simplified Account Access

- Email + Password is now the primary login.
- New email automatically creates a Free account.
- Existing email signs in with its password.
- Normal login no longer depends on Resend/OTP.
- Main Studio is server-gated and redirects directly to Login if no valid session.
- Checkout combines account access and buyer details in one step.
- OTP routes remain only for possible future recovery.
- Protected main Studio is no longer precached by the PWA.
